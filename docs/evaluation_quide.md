## Workflow 

First you need to activate the environment:
```
& C:/Users/Bende/Documents/panther-pose/venv/Scripts/Activate.ps1
```

To test the perfromance in general, you can execute:
```
python .\testing_evaluation.py
```
and adjust the input arguments accordingly. This script also creates the per_image_metrics.csv file that includes the scores and the timening for inference (the inference is done with imgsz=1920)

In a similar way, pose metrcis can be generated by executing the following script:
```
python .\pose_metrics_analysis.py
```
and again adjust path to model and the test split.

To test orientation based on the keypoints, you need to execute the following script:
```
python .\test_orientation.py --count 38
```
and adjust the paths accordingly.

To correct orientation using PCA and Canny, you need to execute:
```
python test_orientation_PCA_Canny_Json.py
```
This currently has an updated visualisation overlay using the arrow.


To express the value in blender simulation convention: (0=right, 90=down, 180=left, 270=up), you need to execute:
```
python test_orientation_PCA_Canny_Json_comparison.py --count 40
```
This will create the file *heading_debug.json*

To transform the format in the appropriate one for comparison, you need to execute:
```
python .\transform_heading_json_to_csv.py
```
This will create the file *heading_estimation_from_debug.csv*

To evaluate the performance of heading inference you need to execute the:
```
python .\combine_inference_with_ground_truth.py
```
which will create the file *inference_with_ground_truth_final.json*

Next, in ordre to visualise the perfromance of the inference, you ned to execute the following script:
```
python .\visualize_heading_inference_performance.py
```
which will create the appropriate graphs



To evaluate the apex accuracy, you need to execute the following script:
```
python.exe test_apex_distance_error.py --version v1 --count 40
```


### Notes
The first image typically takes more time due to model warm-up overhead. This is a common phenomenon in machine learning inference:

-GPU memory allocation: The first inference call allocates memory on the GPU for weights, activations, and outputs
-CUDA kernel compilation: GPU kernels get compiled/optimized on the first run
-Model initialization: Model state is set up and optimized
-Cache population: GPU and system caches are populated
-JIT compilation: Some operations may be JIT compiled

Subsequent inferences are faster because all this initialization is already done - the model is "warm" and ready to go.
